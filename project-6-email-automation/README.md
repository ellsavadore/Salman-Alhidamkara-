# Bulk Email Automation

## Deskripsi
Script Python untuk mengirim email massal secara otomatis dengan personalisasi.

## Fitur
- Kirim email ke banyak penerima sekaligus
- Personalisasi nama penerima
- Support attachment (opsional)
- Schedule pengiriman (dengan cron job)

## Tools
- Python (smtplib, email library)
- Google Sheets API (opsional untuk data penerima)
