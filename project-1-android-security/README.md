# Eksploitasi Keamanan Android 13

## Deskripsi
Penelitian skripsi yang mengidentifikasi dan mengeksploitasi celah keamanan pada sistem operasi Android 13 menggunakan Metasploit framework.

## Tools yang Digunakan
- Metasploit Framework
- Kali Linux
- Android Virtual Device (AVD)
- Nmap

## Langkah Eksploitasi
1. Setup listening listener di Metasploit
2. Generate payload untuk Android
3. Install payload di target device
4. Remote access dan eksekusi perintah

## Hasil Penelitian
Berhasil menemukan kerentanan pada Android 13 yang dapat dieksploitasi untuk mendapatkan akses remote.
