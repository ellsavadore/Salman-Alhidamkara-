# MikroTik Router Configuration

## Deskripsi
Konfigurasi router MikroTik untuk kebutuhan jaringan skala kecil (warnet/kantor).

## Fitur Konfigurasi
- DHCP Server
- NAT (Network Address Translation)
- Firewall rules
- Bandwidth management
- Hotspot setup (opsional)

## Tools
- MikroTik RouterOS
- WinBox / CLI
