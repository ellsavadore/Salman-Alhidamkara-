# Simulasi Serangan Phishing (Edukasi)

## Deskripsi
Simulasi serangan phishing untuk tujuan edukasi keamanan informasi. Digunakan untuk meningkatkan kesadaran pengguna tentang bahaya phishing.

## Tools yang Digunakan
- Social Engineering Toolkit (SET)
- Gophish (Open Source Framework)
- Python

## Fitur
- Template email phishing yang realistis
- Landing page simulasi
- Tracking klik dan data input
- Report hasil simulasi

## Peringatan
Proyek ini untuk TUJUAN EDUKASI dan PELATIHAN keamanan saja. Jangan digunakan untuk aktivitas ilegal.
