# Sales Data Analysis

## Deskripsi
Analisis data penjualan menggunakan Python untuk mengidentifikasi tren dan pola pembelian.

## Tools yang Digunakan
- Python (pandas, numpy, matplotlib, seaborn)

## Fitur
- Load dan bersihkan data
- Visualisasi tren penjualan
- Identifikasi produk terlaris
- Prediksi sederhana
