# Network Vulnerability Scanner

## Deskripsi
Tool sederhana untuk melakukan scanning jaringan dan identifikasi perangkat yang terhubung.

## Tools yang Digunakan
- Python (socket, subprocess)
- Nmap (integrasi)
- Wireshark (opsional)

## Fitur
- Scan IP aktif dalam jaringan
- Identifikasi open ports
- OS fingerprinting sederhana
- Export hasil scan ke file
