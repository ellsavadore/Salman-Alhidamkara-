# To-Do List App

## Deskripsi
Aplikasi web sederhana untuk mencatat daftar tugas dengan fitur CRUD (Create, Read, Update, Delete).

## Fitur
- Tambah tugas baru
- Tandai tugas selesai
- Edit tugas
- Hapus tugas
- Filter tugas (semua/selesai/belum selesai)
- Penyimpanan data di Local Storage

## Teknologi
- HTML5
- CSS3
- JavaScript
