# Sistem Absensi QR Code berbasis Google Sheet

## Deskripsi
Sistem absensi otomatis menggunakan QR Code yang terintegrasi dengan Google Sheet. Pengguna cukup scan QR Code, data kehadiran langsung tercatat secara real-time.

## Fitur
- Scan QR Code untuk absen masuk/keluar
- Pencatatan otomatis ke Google Sheet
- Data real-time bisa diakses dari mana saja
- Timestamp otomatis (tanggal dan jam)
- Validasi duplikasi (mencegah absen ganda)

## Tools yang Digunakan
- Google Sheet
- Google Apps Script
- QR Code Generator
- HTML/CSS (untuk halaman scan)

## Cara Penggunaan
1. Copy script ke Google Apps Script
2. Deploy sebagai web app
3. Generate QR Code dari URL web app
4. Scan QR Code untuk absen
